# บทนำ (Introduction)

ยินดีต้อนรับสู่โปรเจกต์ **Linux Kernel Build Lab**! เอกสารฉบับนี้จัดทำขึ้นเพื่อเป็นคู่มือและรายงานสำหรับ Mini-Project 1 ซึ่งเป็นส่วนหนึ่งของรายวิชา **CPE 333 Operating Systems** มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี (KMUTT)

## วัตถุประสงค์ของโปรเจกต์
วัตถุประสงค์หลักของมินิโปรเจกต์นี้ คือการได้รับประสบการณ์การลงมือปฏิบัติจริงกับแกนหลัก (core) ของระบบปฏิบัติการลินุกซ์ เป้าหมายของเราคือการศึกษา คอมไพล์ (compile) และติดตั้งเคอร์เนล (kernel) ของ Ubuntu ใหม่จากซอร์สโค้ด โปรเจกต์นี้จะช่วยให้มีความเข้าใจอย่างลึกซึ้งยิ่งขึ้นเกี่ยวกับการทำงานภายในของระบบปฏิบัติการ การจัดการ dependency และกระบวนการบิลด์ (build process) ที่ขับเคลื่อนระบบปฏิบัติการลินุกซ์ในปัจจุบัน

## การทำงานร่วมกันเป็นทีม
โปรเจกต์นี้เป็นการทำงานร่วมกันเป็นกลุ่ม โดยมีสมาชิกจำนวน 6 ถึง 8 คน การทำงานเป็นทีมช่วยให้เราสามารถแบ่งปันความรับผิดชอบได้ครอบคลุมในทุกส่วน ไม่ว่าจะเป็นการค้นคว้าข้อมูล การเตรียมสภาพแวดล้อมจำลอง การคอมไพล์ การแก้ไขปัญหา (troubleshooting) และการจัดทำเอกสาร เพื่อให้ได้ผลลัพธ์ที่สมบูรณ์ที่สุด

## วิธีการและขั้นตอนการดำเนินงาน
เพื่อให้บรรลุเป้าหมายอย่างปลอดภัยและมีประสิทธิภาพ เราได้กำหนดแนวทางปฏิบัติดังนี้:

1. **การค้นคว้าและข้อมูลอ้างอิง:** เราอ้างอิงกระบวนการทำงานจากเอกสารอย่างเป็นทางการของ [Ubuntu Kernel Documentation](https://ubuntu.com/kernel/docs/how-to/develop-customise/build-kernel/) เพื่อให้มั่นใจว่าขั้นตอนการพัฒนาและปรับแต่งเคอร์เนลเป็นไปตามมาตรฐาน
2. **การเตรียมสภาพแวดล้อมที่ปลอดภัย:** เนื่องจากการปรับเปลี่ยนเคอร์เนลอาจทำให้ระบบหลักเกิดความไม่เสถียรได้ ขั้นตอนการคอมไพล์และติดตั้งทั้งหมดจึงถูกดำเนินการอย่างรัดกุมภายใน **Virtual Machine (VM)** ระบบปฏิบัติการ Linux โดยใช้ซอฟต์แวร์จำลองสภาพแวดล้อม เช่น VMware หรือ VirtualBox วิธีนี้ช่วยให้เราสามารถย้อนกลับ (roll back) ไปยังสถานะที่เสถียรก่อนหน้าได้อย่างง่ายดาย หากระบบเกิดปัญหาในระหว่างการรันเคอร์เนลใหม่
3. **การลงมือปฏิบัติ:** เราจะทำการดึงซอร์สโค้ดของเคอร์เนล ติดตั้งเครื่องมือที่จำเป็นสำหรับการบิลด์ ตั้งค่าเคอร์เนล คอมไพล์ซอร์สโค้ด และสุดท้ายคือการติดตั้งเคอร์เนลอิมเมจและโมดูลต่างๆ ลงในระบบเสมือน (VM) ของเรา

## ผลลัพธ์และสิ่งที่ต้องส่ง (Deliverable)
ผลลัพธ์สุดท้ายของโปรเจกต์นี้คือรายงานที่อธิบายรายละเอียดแบบเป็นขั้นเป็นตอน (step-by-step) โดยจะบันทึกกระบวนการทั้งหมดตั้งแต่การเริ่มต้นตั้งค่า Virtual Machine ไปจนถึงการบูตเข้าสู่เคอร์เนล Ubuntu ตัวใหม่ที่เราคอมไพล์ขึ้นมาได้สำเร็จ ซึ่งเอกสารฉบับนี้จะใช้เป็นทั้งรายงานสำหรับส่งในรายวิชา และเป็นคู่มือสำหรับการทำซ้ำ (reproducible) ในอนาคต
